AudioMicrophone format, signal, gain and packet size
AtomS3U: contributor-tested with BirdNET-Go; built-in PDM microphone. Sense: Experimental — needs more testing; PDM uses its built-in microphone, I2S uses an external microphone. Recording uses its built-in microSD slot. Default: external microphone. Applying restarts audio and saves the board.
Microphone format
Philips I2S is the default for existing installations. Selecting the wrong I2S alignment cannot damage the microphone, but produces bad audio. With the default board option, PDM requires PDM hardware and different wiring: CLK to D3, DATA to D2, SEL to GND; leave D1 (WS) and D7 (MCLK) disconnected. PDM uses 48 kHz and ignores I2S Shift. Switch off power before changing wires.

Low-battery protection

Stops recording and closes the WAV file before the selected action. Requires battery monitoring and a correct voltage reading.

Advanced protection settings

Confirmation ignores brief dips. Recovery requires voltage above the stop voltage plus the recovery margin. Deep sleep has no automatic wake-up. This does not replace the battery pack's hardware protection.
