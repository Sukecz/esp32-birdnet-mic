# Firmware 2.05 validation

This release consolidates Recording, SD log, Battery and power editing into the
shared settings lifecycle and separates firmware responsibilities into audio
capture, RTSP, MQTT, settings persistence, mode control and OTA modules.

Existing NVS keys/defaults, OTA bridge routing, DMA/internal allocation and PSRAM
fallback policies are retained. No new task or audio queue is introduced.

## Validation procedure

- Native/Python and standalone JavaScript regression suites, including production
  settings validation and mode controller modules.
- Source and embedded browser suites, including scoped saves, failed/retried
  saves, draft/revert/discard, stale polling, typography/themes and mobile overflow.
- Six registry target configurations: C3/S3/C5/C6 and S3/C5 without PSRAM.
- Actual app, partition and ELF budgets; source/configuration/artifact hashes.
- C6 OTA, read-only UI and capture/time smoke checks, then observed runtime memory
  under actual RTSP and the optional Listen consumer.

## Measured results (2026-11-02)

- Host regression suite: 138 Python/native tests, one skipped, plus standalone
  native/JavaScript checks passed. All 21 browser suites and the assembly gate
  passed. The migrated settings test covered 60 combinations across five groups,
  source/embedded assets, three widths and both themes.
- All six build configurations and the packaged release checks passed. Four
  standard build receipts share clean source commit `f280f96`; packaged images
  reuse these verified outputs. No new universal heap threshold is inferred.
- C6 was updated locally to 2.05. All 49 compared persistent settings were
  retained, including External antenna. Capture and actual NTP/UTC checks passed.
  Live UI draft/poll/revert/discard, typography and overflow checks passed at
  320/390/1280 px in both themes with device settings writes blocked.
- S3 was updated from 2.03 to 2.05 using the matching verified app image.
  All 25 compared configuration fields were retained. A 30-second web/memory
  observation passed: minimum free internal heap 178,176 B and free PSRAM
  8,220,672 B. Live UI draft/poll/revert/discard, themes and overflow checks passed
  at 320/390/1280 px without settings writes. Microphone and microSD adapter were
  absent, so this does not qualify audio or recording.

## Remaining physical validation
