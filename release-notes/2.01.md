# BirdNETMic 2.01 — in preparation

Fixes Recording memory allocation across XIAO C3/S3/C5/C6. Recording keeps capture
and Listen available while releasing the unused RTSP reserve. Returning to
Streaming releases the SD audio queue before recreating the Streaming reserve.

Listen now has an independent network task and bounded catch-up sending, so
web requests cannot starve its audio queue. Short preview overflows discard stale
preview sound and continue with current PCM, without changing the independent
SD recording. Stalled connections still have a bounded timeout.

S3 builds now enable the board's OPI PSRAM, sharing the C5 external audio-buffer
path and internal-memory fallback. SD card checks have a separate, smaller memory
budget, including the first check after boot. Internal-memory and PSRAM diagnostics
are available on all boards. New recording attempts also report current allocation
failures instead of retaining an earlier card-check error.

See [validation and hardware limits](2.01-validation.md). This candidate has not
been published. Settings, microphone profiles, SD wiring and defaults are retained.
