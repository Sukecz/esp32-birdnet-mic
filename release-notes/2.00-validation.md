# Firmware 2.00 validation — 2026-10-30

All four XIAO targets built and packaged from the release source with the pinned
Arduino dependencies. App sizes: C3 1357205 B, S3 1263612 B, C5 1466835 B;
C6 also passed the configured app-slot size check. The permanent 1.35 bridge is
preserved. Generated manifest and OTA contract agree on 2.00.

108 native/Python tests passed, with the nginx routing test initially skipped;
the three OTA-channel tests then passed using the local nginx binary. Native
discovery/client/time-zone checks and Web UI health/thermal/Recording checks passed.
Browser suites covered setup, battery, antenna, logs, recording, audio playback,
settings lifecycle, polling recovery, OTA and layout, including source/embedded
assets where implemented. The older layout test was updated for the Battery
section and the current 150% playback-volume limit.

Both C5 and C6 received the local 2.00 app over HTTP OTA. Saved settings were
compared before/after. C6 had an unsaved old default SD-log limit of 1024 KiB;
the new default was 977 KiB, so 1024 KiB was explicitly restored and saved.
Final configuration comparisons match, including C5 calibration and C6 External antenna.

- C5: actual mobile browser Start/Stop & save, increasing written audio, finalized
  verified WAV and zero dropped recording samples. Capture healthy, I2S errors 0.
  The PDM startup DMA total is 46, with no current overruns; the strict zero-total
  smoke checker flags that historical startup count. It is not evidence of an SD
  recording gap. The earlier 9-hour recording test remains scoped to its build/card.
- C6: capture healthy, I2S/DMA errors 0, NTP confirmed with accurate UTC/local offset;
  ffmpeg successfully received RTSP/TCP. Actual mobile UI showed 2.00 without JS errors.
- Public flasher preview: 320/390/1280px, light/dark, no horizontal overflow; text
  describes both modes and the new welcome wizard.

C5 ends in Recording mode / Saved; C6 remains Streaming with External antenna.
No new unattended recording was left running. Multi-day battery endurance is an
estimate, not a completed discharge test. Sense remains experimental.
